# Specification Section: Compliance Mapping Data Model (T-02802)

## 1. Scope & Interfaces
Defined standard taxonomies (`ComplianceFramework`), status state machine (`ComplianceStatus`), substrate target bindings (`SubstrateTargetType`), mapping entries (`ComplianceMappingEntry`), and snapshot persistence (`ComplianceCatalogSnapshot`).

## 2. Reused vs New Interfaces
- Reused:
  - `utcnow_iso` from `canonical.rs`.
  - Serde JSON serialization contracts.
- New (AIOS-specific):
  - `ComplianceFramework`, `ComplianceStatus`, `SubstrateTargetType`.
  - `ComplianceControl`, `ComplianceMappingEntry`, `ComplianceCatalogSnapshot`.
  - Validation bounds `MAX_COMPLIANCE_ID_LEN`, `MAX_COMPLIANCE_TITLE_LEN`, etc.
