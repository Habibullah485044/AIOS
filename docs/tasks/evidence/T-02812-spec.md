# Specification Section: Compliance Mapping Core Service (T-02812)

## 1. Scope & Interfaces
Specified `ComplianceService` and `ComplianceAssessmentReport`.
- Input validation: `validate_path` rejecting `..`, control characters, UNC paths, and symlinks.
- Persistence: `load_from_path` (bounded at 1 MiB) and `save_to_path` (atomic temp write and rename).
- Assessment engine: `assess_framework` computing overall and scoped compliance ratios and gaps.
- PEP binding: `verify_pep_coverage` asserting active controls exist for critical enforcement gates.

## 2. Reused vs New Interfaces
- Reused:
  - `ComplianceCatalogSnapshot`, `ComplianceMappingEntry`, `ComplianceFramework`, `ComplianceStatus` from `compliance_data_model.rs`.
  - `utcnow_iso` from `canonical.rs`.
- New (AIOS-specific):
  - `ComplianceAssessmentReport`.
  - `ComplianceService`.
