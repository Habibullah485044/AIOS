# Specification Section: Compliance Mapping CLI Surface (T-02822)

## 1. Scope & Interfaces
Defined `aiosh compliance` command grammar, subcommands (`list`, `show`, `register`, `status`, `assess`, `check-pep`, `init`), standard exit codes (0, 1, 2, 3), audit logging bindings, and terminal output sanitization rules.

## 2. Reused vs New Interfaces
- Reused:
  - `ComplianceService`, `ComplianceCatalogSnapshot`, `ComplianceMappingEntry` from `aiosh-core`.
  - `classify_and_emit`, `open_context`, `has_flag`, `parse_flag`, `sanitize_terminal` from `aiosh-cli`.
- New (AIOS-specific):
  - `cmd_compliance` dispatcher and subcommand handlers.
