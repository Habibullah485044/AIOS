## 2. Security Audit & Threat Modeling
- **Positive vs Negative Attestation**: Proving an action *did not* happen cannot rely on empty logs.
- **Threat T-1 (Covert Re-Chaining)**: Analyzed `AuditRing` in `code/aiosh-cli/src/audit.ts`. Without external anchoring, anyone holding `audit.db` can drop a row and re-chain SHA-256 hashes cleanly.
- **Mitigation (Layer 1 + Layer 2)**:
  - Layer 1: Consequential resources require redeeming a single-use capability token.
  - Layer 2: External signing of chain head hashes (`anchors.jsonl`) + Bloom filter fast exclusion on archived segments.
  - Layer 3: Hardware Enclaves (TEE) targeted for Phase 6.
