## 1. Scope & Objective

## 2. Interface Contracts

### 2.1 Type Extensions (`code/aiosh-cli/src/types.ts`)

export interface CreateOpts {

### 2.2 Database Schema Migration (`pep_grants` in `audit.db`)
Add columns via `maybeAddColumn_`:
- `single_use INTEGER NOT NULL DEFAULT 1`
- `redeemed_at TEXT`

### 2.3 `PepGrantManager.create()` Contract
- **Inputs**: `opts: CreateOpts`, `ring?: AuditRing`
- **Behavior**:
  1. Generate `grant_id = "gr_" + randomBytes(8).toString("hex")`.
  2. Insert row into `pep_grants` table with `single_use = opts.single_use ?? 1`.
  3. If `ring` is provided, append audit row:
     - `actor`: `"user"`
     - `actor_id`: `opts.issued_to`
     - `tool`: `"pep.capability.mint"`
     - `command`: `"grant.mint"`
     - `grant_token`: `grant_id`
     - `args`: `{ grant_id, single_use: boolean, scope: opts.scope, expires_at: string }`
     - `outcome`: `"success"`
- **Returns**: `PepGrant` object.

### 2.4 `PepGrantManager.redeem()` Contract
- **Inputs**: `grant_id: string`, `actor: string`, `tool: string`, `command: string`, `ring?: AuditRing`
- **Behavior**:
  1. Lookup grant from `pep_grants`.
  2. If missing $\to$ return `{ ok: false, reason: "grant not found" }`.
  3. If `revoked_at != null` $\to$ return `{ ok: false, reason: "grant revoked" }`.
  4. If `expires_at < now` $\to$ return `{ ok: false, reason: "grant expired" }`.
  5. If `single_use == 1` and `redeemed_at != null` $\to$ return `{ ok: false, reason: "grant already redeemed" }`.
  6. Execute SQL update: `UPDATE pep_grants SET redeemed_at = ? WHERE grant_id = ? AND redeemed_at IS NULL`.
  7. If update affected 0 rows (concurrent race) $\to$ return `{ ok: false, reason: "grant already redeemed (race condition)" }`.
  8. If `ring` is provided, append audit row:
     - `actor`: `"agent"`
     - `actor_id`: `actor`
     - `tool`: `"pep.capability.redeem"`
     - `command`: command
     - `grant_token`: `grant_id`
     - `args`: `{ grant_id, tool, command }`
     - `outcome`: `"success"`
- **Returns**: `RedeemResult` with `audit_hash`.

## 3. Failure Modes & Error Envelopes

| Failure Case | HTTP / RPC Code | Refusal Reason | Audit Effect |
|---|---|---|---|
| Non-existent token | 404 / InvalidParams | `"grant not found"` | Writes `pep.refusal` audit row |
| Expired token | 403 / PermissionDenied | `"grant expired"` | Writes `pep.refusal` audit row |
| Revoked token | 403 / PermissionDenied | `"grant revoked"` | Writes `pep.refusal` audit row |
| Token already redeemed | 409 / Conflict | `"grant already redeemed"` | Writes `pep.refusal` audit row |
| Scope mismatch | 403 / PermissionDenied | `"tool 'X' not authorised by grant"` | Writes `pep.refusal` audit row |
