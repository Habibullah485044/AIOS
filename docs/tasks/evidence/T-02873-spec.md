## 1. Specification Overview
The Standalone Proof Verifier evaluates a `RestraintProofPackage` without accessing `audit.db`, the agent host, or any privileged service. It depends purely on cryptographic primitives (Ed25519 signature checks, SHA-256 hash chains, and deterministic Bloom filters).

## 3. Detailed Verification Stages & Checks

The verifier executes 7 sequential gates:

1. **`CHECK_SCHEMA`**:
   - Parses payload (JSON string or dict).
   - Validates `schema_version === 1`.
   - Validates presence of `proof_id`, `grant`, `window`, `anchors`, `segments_checked`, `live_range`.
   - Failure: `VERIFY_FAILED: INVALID_SCHEMA`

2. **`CHECK_GRANT`**:
   - `grant.redeemed_at === null`
   - `grant.single_use === true`
   - Grant validity bounds requested window:
     `grant.issued_at <= window.start` and `grant.expires_at >= window.end`
   - Failure: `VERIFY_FAILED: GRANT_INVALID` or `VERIFY_FAILED: GRANT_REDEEMED`

3. **`CHECK_ANCHOR_KEYS`**:
   - `start_anchor.pubkey` in `trusted_pubkeys`
   - `end_anchor.pubkey` in `trusted_pubkeys`
   - Failure: `VERIFY_FAILED: UNTRUSTED_KEY`

4. **`CHECK_ANCHOR_SIGS`**:
   - Ed25519 verification on `start_anchor` payload using `start_anchor.pubkey` and `start_anchor.signature`
   - Ed25519 verification on `end_anchor` payload using `end_anchor.pubkey` and `end_anchor.signature`
   - Failure: `VERIFY_FAILED: INVALID_ANCHOR_SIGNATURE`

5. **`CHECK_ANCHOR_BOUNDS`**:
   - `start_anchor.timestamp <= window.start`
   - `end_anchor.timestamp >= window.end`
   - `start_anchor.seq <= end_anchor.seq`
   - Failure: `VERIFY_FAILED: UNBOUNDED_WINDOW`

6. **`CHECK_BLOOM_EXCLUSION`**:
   - For each segment in `segments_checked`:
     - $segment.row\_range[0] \ge start\_anchor.seq$ and $segment.row\_range[1] \le end\_anchor.seq$
     - Evaluate `bloom_test(bytes.fromhex(segment.bloom_hex), m, k, grant_id)`
     - Result MUST be `False` (negative). If `True`, proof fails.
   - Failure: `VERIFY_FAILED: BLOOM_INDICATES_PRESENCE`

7. **`CHECK_LIVE_CHAIN`**:
   - If `live_range.hashes` is non-empty:
     - `live_range.hashes[-1] === end_anchor.head_hash`
   - Failure: `VERIFY_FAILED: HEAD_HASH_MISMATCH`
