## Shipped Capability (hand-over summary)

**Proof of Restraint** lets AIOS cryptographically prove a negative: *a capability was granted and then left untouched* — without trusting operator logs. Chain: mint (PEP grant) → anchor (Ed25519 checkpoints over the audit-ring tail) → prove (`restraint.generate_restraint_proof`) → verify anywhere, zero database (`verifier.verify_restraint_proof` / `python -m aiosh_mcp.verifier <proof.json> --pubkey <hex>`).

The conformance gate (`python3 tools/test_por_conformance_suites.py`, CI suite `por_conformance`) re-proves the mint→anchor→prove→verify loop on every CI run, so drift is caught mechanically.
