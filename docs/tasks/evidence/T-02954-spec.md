# Specification Evidence: Compliance Mapping Recovery & Validation (T-02954)

- **Subsystem**: Phase 2 — Security Kernel & PEP Fabric / Compliance Mapping / Recovery & Validation
- **Task ID**: `T-02954`
- **Normative Spec Document**: `docs/SPEC-COMPLIANCE-RECOVERY.md`

## 1. Scope & Interface Classification

### 1.1 Reused Interfaces
- `ComplianceCatalogSnapshot`, `ComplianceMappingEntry` (`code/aiosh-rust/aiosh-core/src/compliance_data_model.rs`)
- `ComplianceService` (`code/aiosh-rust/aiosh-core/src/compliance_service.rs`)
- `aios.compliance` tool envelope in `server.py` and `compliance.py`
- `_recorded_call` audit wrapper

### 1.2 New Interfaces
- `ComplianceCatalogStatus`: Healthy, Corrupt, Missing, CapacityExceeded
- `ComplianceIntegrityReport`: Status, file size, mapping count, issues list
- `ComplianceRecoveryResult`: Success, mappings recovered, quarantine path, backup path
- `ComplianceRecoveryService`: `verify_integrity`, `create_backup`, `repair_catalog`, `restore_from_backup`, `validate_path`
- New actions on `aios.compliance`: `"recovery-verify"`, `"recovery-backup"`, `"recovery-repair"`, `"recovery-restore"`

### 1.3 Invariants Certified
- `COMPLYREC1`: Non-destructive integrity verification.
- `COMPLYREC2`: Deterministic atomic backup creation.
- `COMPLYREC3`: Quarantine preservation for corrupted files (`.corrupt.<pid>.<nanos>`).
- `COMPLYREC4`: Path traversal sanitization (CWE-22) rejecting `..`, UNC paths, control characters.
- `COMPLYREC5`: Safe canonical baseline fallback when primary and backup are unrecoverable.
- Proof-of-Restraint `I-2`: `recovery-verify` is read-only; mutating recovery actions require PEP capability token.

## 2. Error Code Taxonomy
- `COMPLYREC_ERR_PATH_TRAVERSAL`: Path traversal or device path detected.
- `COMPLYREC_ERR_CORRUPT`: Unrecoverable file syntax or schema corruption.
- `COMPLYREC_ERR_NO_BACKUP`: Backup file `.bak` does not exist for restore operation.
- `COMPLYREC_ERR_IO`: Filesystem I/O failure during atomic rename or write.
- `COMPLYREC_ERR_CAPACITY`: Entry capacity exceeded limit (> 1024 entries).
