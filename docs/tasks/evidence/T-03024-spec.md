## 1. Scope & Objective

Defines the security policy framework governing Incident Response Runbooks and SecTools scanning. The policy layer operates between the external invocation point (FastMCP `aios_runbook` / CLI `aiosh runbook`) and the execution substrate, strictly bounding blast radius, preventing accidental self-inflicted outages, enforcing operator confirmations (Proof-of-Restraint), and preventing unchecked port/file scanning.

---

## 2. Types & Data Contract

### 2.1 Enforcement Modes (`RunbookEnforcementMode`)
- `Enforcing`: Fail-closed on any policy violation. (Default).
- `Permissive`: Emits warning audit rows but permits execution.
- `Disabled`: Policy evaluation bypassed completely.

### 2.2 Security Policy Structure (`RunbookSecurityPolicy`)
```rust
pub struct RunbookSecurityPolicy {
    pub version: String,
    pub mode: RunbookEnforcementMode,
    pub require_operator_confirmation_for_high_risk: bool,
    pub max_step_timeout_seconds: u64,
    pub max_active_sessions: u32,
    pub disallowed_categories: Vec<IncidentCategory>,
    pub disallowed_substrates: Vec<RunbookTargetSubstrate>,
    pub max_scanned_ports: usize,
    pub max_file_scan_depth: usize,
    pub max_file_scan_size_bytes: u64,
    pub require_pep_grant: bool,
}
```

### 2.3 Policy Evaluation Interface
- `evaluate_runbook_start(policy: &RunbookSecurityPolicy, spec: &RunbookSpec) -> Result<(), String>`
- `evaluate_step_advance(policy: &RunbookSecurityPolicy, step: &RunbookStep, operator_confirmed: bool) -> Result<(), String>`
- `evaluate_scan_operation(policy: &RunbookSecurityPolicy, action: &str, ports_count: usize, depth: usize) -> Result<(), String>`
- `load_from_file(path: &str) -> Result<RunbookSecurityPolicy, String>`
- `save_to_file(&self, path: &str) -> Result<(), String>`
