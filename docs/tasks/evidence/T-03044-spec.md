### 1.2 New Interfaces
- `RunbookDocCategory` enum:
  - `Architecture`, `DataModel`, `Lifecycle`, `SecurityTools`, `Policy`, `Observability`, `Recovery`
- `RunbookDocSection` struct:
  - `title: String`, `content: String`
- `RunbookDocTopic` struct:
  - `id: String`, `title: String`, `category: RunbookDocCategory`, `summary: String`, `sections: Vec<RunbookDocSection>`, `related_topics: Vec<String>`
  - `to_markdown() -> String`
- `RunbookDocSearchResult` struct:
  - `topic_id: String`, `title: String`, `category: RunbookDocCategory`, `score: usize`, `snippet: String`
- `RunbookDocRepository` service:
  - `list_topics() -> &[RunbookDocTopic]`
  - `get_topic(id: &str) -> Option<&RunbookDocTopic>`
  - `list_by_category(category: RunbookDocCategory) -> Vec<&RunbookDocTopic>`
  - `search(query: &str, category: Option<RunbookDocCategory>) -> Result<Vec<RunbookDocSearchResult>, String>`
- FastMCP tool surface actions:
  - `aios_runbook(action="doc_list")`
  - `aios_runbook(action="doc_get", runbook_id="...")`
  - `aios_runbook(action="doc_search", parameters={"query": "...", "category": "..."})`

### 1.3 AIOS-Specific Proposals
- In-memory compile-time seeded canonical playbook and diagnostic tool knowledge repository enabling air-gapped, zero-network incident response lookup.
- Strict bounded query string caps ($\le 128$ characters), snippet caps ($\le 200$ chars), and result caps ($\le 10$ items) preventing memory ballooning and algorithmic complexity denial of service.

## 2. Invariants Certified

- `IRDOC1`: Pre-seeded in-memory repository with canonical reference playbooks and scan tool docs.
- `IRDOC2`: Ranked search over tokens with deterministic score ordering (title weight 10, summary weight 5, section content weight 1).
- `IRDOC3`: Bounded query length ($\le 128$ characters) and result list ($\le 10$ items).
- `IRDOC4`: Topic ID sanitization rejecting path traversal (`..`), path separators (`/`, `\`), control characters, and zero-width/bidirectional unicode overrides.
- `IRDOC5`: Comprehensive coverage across incident response lifecycle, tools, policy, telemetry, and recovery.

## 3. Error Code Taxonomy

- `IRDOC_ERR_NOT_FOUND`: `"IRDOC_ERR_NOT_FOUND"` — Requested topic ID does not exist in repository.
- `IRDOC_ERR_QUERY_BOUNDS`: `"IRDOC_ERR_QUERY_BOUNDS"` — Search query exceeds 128 characters or is empty after sanitization.
