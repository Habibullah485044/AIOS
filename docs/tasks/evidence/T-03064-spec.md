## 2. Invariants (MCPDM-INV1..MCPDM-INV5)

- **MCPDM-INV1 (Protocol Conformance)**:
  All requests, responses, and notifications strictly conform to JSON-RPC 2.0 with pinned MCP protocol version `"2025-06-18"`.
- **MCPDM-INV2 (Bounded Memory & DoS Prevention)**:
  Payload sizes, identifiers, schema lengths, argument sizes, and content block counts are hard-capped.
- **MCPDM-INV3 (Control Character & Bidi Sanitization)**:
  Identifiers (names, session IDs, method names) must reject control characters (`\x00..\x1F`, `\x7F`) and Trojan Source bidirectional overrides (`\u202A..\u202E`, `\u2066..\u2069`).
- **MCPDM-INV4 (ADR-0035 §AF-2 Envelope)**:
  Result structures must wrap in deterministic envelopes preserving error diagnostics and preventing unhandled panics/exceptions.
- **MCPDM-INV5 (Capability & Grant Provenance)**:
  Tool invocations carry optional capability grant tokens (`grant_id`) to support downstream Policy Enforcement Point (PEP) verification.

## 3. Data Structures & Schema

### Request ID
Supports polymorphic JSON-RPC IDs (Integer or String):
```rust
#[derive(Debug, Clone, PartialEq, Eq, Hash, Serialize, Deserialize)]
#[serde(untagged)]
pub enum McpRequestId {
    Number(i64),
    String(String),
}
```

### JSON-RPC 2.0 Framing
```rust
pub struct McpJsonRpcRequest {
    pub jsonrpc: String, // "2.0"
    pub id: McpRequestId,
    pub method: String,
    pub params: Option<serde_json::Value>,
}

pub struct McpJsonRpcResponse {
    pub jsonrpc: String, // "2.0"
    pub id: McpRequestId,
    pub result: Option<serde_json::Value>,
    pub error: Option<McpJsonRpcError>,
}

pub struct McpJsonRpcError {
    pub code: i64,
    pub message: String,
    pub data: Option<serde_json::Value>,
}
```

### Tool Definitions & Results
```rust
pub struct McpToolDefinition {
    pub name: String,
    pub description: String,
    pub input_schema: serde_json::Value,
}

pub struct McpToolCall {
    pub name: String,
    pub arguments: serde_json::Value,
    pub grant_id: Option<String>,
}

pub enum McpContentBlock {
    Text { text: String },
    Image { data: String, mime_type: String },
    Resource { uri: String, mime_type: Option<String>, text: Option<String> },
}

pub struct McpToolResult {
    pub content: Vec<McpContentBlock>,
    pub is_error: bool,
}
```

### Session & Capabilities

pub struct McpServerCapabilities {
    pub tools: bool,

pub struct McpSessionInfo {

## 4. Failure Modes & Audit Effects

| Operation | Failure Condition | Error Code | Audit Impact |
| :--- | :--- | :--- | :--- |
| `parse_request` | Non-JSON or missing `jsonrpc: "2.0"` | `-32700` / `-32600` | Logged to stderr / diagnostic ring |
| `validate_name` | Name contains bidi / control / length > 64 | `-32003` | Rejection event emitted |
| `call_tool` | Arguments exceed 1 MiB | `-32002` | Policy violation logged |
| `call_tool` | Unauthorized without required grant | `-32001` | PEP security audit row recorded |
