## 2. Invariants (MCPSVC-INV1..MCPSVC-INV5)

- **MCPSVC-INV1 (Thread-Safe Concurrency)**: Tool registry and session storage operate with synchronized concurrency guards (Mutex / RWLock in Rust, thread-safe dict / asyncio lock in Python).
- **MCPSVC-INV2 (Session Lifecycle & Pruning)**: State transitions strictly enforce `Initializing -> Active -> Idle -> Terminated`. Max active sessions bounded to 64; expired/terminated sessions pruned automatically.
- **MCPSVC-INV3 (Fail-Closed Dispatch Routing)**: Invocations targeting unknown tools or tools requiring grants without valid tokens fail immediately with explicit JSON-RPC error codes.
- **MCPSVC-INV4 (ADR-0035 §AF-2 Result Envelopes)**: All operations wrap outputs in standardized `McpCoreResultEnvelope<T>` guaranteeing that unexpected errors do not crash the service.
- **MCPSVC-INV5 (Proof-of-Restraint Audit Binding)**: State-changing dispatches verify capability tokens and emit tamper-evident audit rows to the SQLite WAL ring.

### Session Record

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum McpSessionStatus {
    Initializing,
    Active,
    Idle,
    Terminated,
}

pub struct McpSessionRecord {
    pub info: McpSessionInfo,
    pub status: McpSessionStatus,
    pub last_heartbeat: u64,
}
```

### Core Service API
```rust
pub struct McpServerCoreService {
    // Thread-safe tool catalog and active session table
}

impl McpServerCoreService {
    pub fn new() -> Self;
    pub fn register_tool(&self, def: McpToolDefinition) -> Result<(), McpJsonRpcError>;
    pub fn unregister_tool(&self, name: &str) -> Result<bool, McpJsonRpcError>;
    pub fn get_tool(&self, name: &str) -> Option<McpToolDefinition>;
    pub fn list_tools(&self) -> Vec<McpToolDefinition>;

    pub fn create_session(&self, session_id: &str, client_name: &str, client_ver: &str) -> Result<McpSessionRecord, McpJsonRpcError>;
    pub fn heartbeat_session(&self, session_id: &str) -> Result<(), McpJsonRpcError>;
    pub fn terminate_session(&self, session_id: &str) -> Result<(), McpJsonRpcError>;
    pub fn get_session(&self, session_id: &str) -> Option<McpSessionRecord>;

    pub fn dispatch_tool_call(&self, call: McpToolCall) -> Result<McpToolResult, McpJsonRpcError>;
    pub fn safe_dispatch_tool_call(&self, call: McpToolCall) -> McpCoreResultEnvelope<McpToolResult>;
}
```
