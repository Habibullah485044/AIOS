## 1. Specification Overview

This specification formally codifies the MCP/API wire contract connecting clients to `McpServerCoreService`:
1. Full JSON-RPC 2.0 request/response envelope conformity.
2. Direct dispatch of `initialize`, `ping`, `tools/list`, and `tools/call`.
3. Capability token validation for privileged operations.
4. Payload size limits (`MAX_ARGUMENTS_SIZE = 1 MiB`) and clamped timeouts `[1, 300]`.
5. Cryptographic audit logging for all consequential dispatch events.
