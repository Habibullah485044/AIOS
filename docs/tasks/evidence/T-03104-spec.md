## 1. Specification Overview

This specification establishes the schema and validation invariants for MCP Server Core configuration:
1. Codified parameters: `store_path`, `max_active_sessions`, `session_idle_timeout_seconds`, `default_execution_timeout_seconds`, `max_arguments_size_bytes`, `max_tools_count`, `require_admin_grant`, `auto_prune_terminated`.
2. Bounded validation ranges protecting memory, session capacity, and execution durations.
3. Precedence hierarchy: CLI flags > Environment variables > JSON config file > Hardcoded defaults.
4. Bounded configuration file size ceiling of 64 KiB (`MAX_CONFIG_FILE_BYTES`).
