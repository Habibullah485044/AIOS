# T-03254 Specification: Model Backend Adapters Recovery & Validation

## Contract Specification
Reference document: `docs/SPEC-MODEL-BACKEND-ADAPTERS-RECOVERY.md`.

### 1. Invariants
- `MODRECV-INV1`: `total_models == valid_models + invalid_models`.
- `MODRECV-INV2`: `is_healthy == (len(issues) == 0 and invalid_models == 0)`.
- `MODRECV-INV3`: Traversal & Injection immunity (`validate_model_store_path`).
- `MODRECV-INV4`: PoR Invariant I-2 gating (validation is 0 tokens, recovery requires capability token).
- `MODRECV-INV5`: Atomic quarantine before overwrite.

### 2. Error Envelopes & Return Types
All calls return structured dicts:
- On success: `{"status": "success", "ok": True, "data": ...}`
- On failure: `{"status": "error", "ok": False, "error": CODE, "message": str}`

### 3. Error Codes
- `MODRECV_ERR_INVALID_PATH`
- `MODRECV_ERR_CORRUPT_JSON`
- `MODRECV_ERR_SCHEMA_VIOLATION`
- `MODRECV_ERR_UNAUTHORIZED`
- `MODRECV_ERR_IO`
- `MODRECV_ERR_INTERNAL`
