# T-03264 Specification: Agent Loop Hardening Data Model

## Contract Specification
Reference document: `docs/SPEC-AGENT-LOOP-HARDENING-DATA-MODEL.md`.

### 1. Invariants
- `LOOPDATA-INV1`: Monotonic contiguous step indexing (`step_index == previous + 1`).
- `LOOPDATA-INV2`: Token non-negativity and conservation (`total_tokens_used == sum(s.tokens_consumed)`).
- `LOOPDATA-INV3`: Circuit-breaker enforcement on consecutive failures (`consecutive_failures <= consecutive_failure_limit`).
- `LOOPDATA-INV4`: Clean serialization parity (`to_dict` / `from_dict`) with secret masking.
- `LOOPDATA-INV5`: Deterministic finite state machine transitions.

### 2. State Machine Enum (`LoopState`)
`INIT`, `OBSERVE`, `PLAN`, `EVALUATE_POLICY`, `EXECUTE_TOOL`, `RECORD_STEP`, `COMPLETED`, `FAILED`, `ABORTED`.

### 3. Data Models
- `LoopConfig` (frozen)
- `LoopStepRecord`
- `LoopSnapshot`
